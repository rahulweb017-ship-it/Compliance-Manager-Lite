Frequently asked questions

Everything buyers usually ask before installing.

Which Odoo versions are supported?

Odoo 18.0 and 19.0, on both Community and Enterprise editions.

Do I need to install anything else?

No. The app depends only on base, mail and web, all part of standard Odoo.

How are the reminder emails sent?

A scheduled action runs once a day and uses your Odoo outgoing mail server, so make sure one is configured.

Can I change the reminder days?

Yes. Open Compliance Manager > Configuration > Settings and set the four intervals to any number of days.

Who receives the reminder?

Only the responsible user set on the record, and only if they have an email address.

What happens when I renew a document?

Update the expiry date. The status recalculates and the reminder cycle resets, so the next renewal is tracked from scratch.

Can every employee see all documents?

No. A record rule limits Compliance Users to their own assigned records. Only Compliance Managers see everything.

Is it really free?

Yes. The app is published under LGPL-3 at no cost, and you are free to adapt it to your needs.
