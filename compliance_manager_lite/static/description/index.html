How reminders work

✓  A scheduled action refreshes every status and sends emails once per day.

✓  Only the responsible user is notified, so inboxes stay clean.

✓  Every reminder is written to a history log, so the same one is never sent twice.

✓  Failed sends are recorded with their error and retried on the next run.

✓  Change an expiry date and the whole reminder cycle restarts automatically.

✓  Expired records stay flagged until you renew or archive them.

FAQ

Frequently asked questions

Everything buyers usually ask before installing.

Which Odoo versions are supported?

Odoo 17.0, 18.0 and 19.0, on both Community and Enterprise editions.

Do I need to install anything else?

Only standard Odoo apps. It depends on base, mail, web and Employees (hr) — Employees provides the Department field and is free in Community. There are no third-party services and no paid modules.

How are the reminder emails sent?

A scheduled action runs once a day and uses your Odoo outgoing mail server, so make sure one is configured.

Can I change the reminder days?

Yes. The defaults are 90, 60, 30, 15, 7 and 1 day, and you can add or remove any interval under Configuration > Default Reminder Schedule. Each category can also carry its own schedule, so vehicle insurance and employee passports can be reminded on completely different timelines.

Who receives the reminder?

Only the responsible user set on the record, and only if they have an email address.

What happens when I renew a document?

Update the expiry date. The status recalculates and the reminder cycle resets, so the next renewal is tracked from scratch.

Can every employee see all documents?

No. A record rule limits Compliance Users to their own assigned records. Only Compliance Managers see everything.

Is it really free?

Yes. The app is published under LGPL-3 at no cost, and you are free to adapt it to your needs.
